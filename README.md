# Agent Playbooks

Copy-paste setups for AI agents: Grok Bot, Claude Code, Codex, Cursor.
Each playbook is one idea that saves hours or money, the exact prompt or template to use, and where it came from.

Animated versions of every playbook are on X: [@Vexo_x1](https://x.com/Vexo_x1)

## Playbooks

| Playbook | Agent | What it fixes |
|---|---|---|
| [Hire Claude, don't prompt it](claude-code/job-description.md) | Claude Code | An agent with a job description, a morning brief, three request lanes and a Friday grade from you |
| [Stop paying for empty runs](grok-bot/routine-audit.md) | Grok Bot | Routines that wake up every hour to find nothing new |

## Rules for this repo

- Every number says where it came from. If it's someone else's math, it's labeled as theirs.
- Every idea credits the person who shared it, with a link.
- Templates are starting points. Change them for your own setup and check the results yourself.

## Contributing

Found a mistake, or tried a playbook and got different numbers? Open an issue. Real results beat clean theory.
